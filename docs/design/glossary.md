# Glossary

| Term | Meaning |
| --- | --- |
| **Villain** | A player's character. Each player drafts 3, which act as lives. One is active at a time. |
| **Active Villain** | The Villain currently running your dungeon and fighting Heroes who reach the end of it. |
| **Vanquished** | A Villain beaten by a Hero. The next one takes over, or the player is eliminated. |
| **Eliminated** | A player who has lost all 3 Villains. They can't win. |
| **Overlord** | The winner: the surviving player with the most Objectives claimed. |
| **Objective Market** | The shared, face-up row of Objectives (players + 2). Any villain can race to complete them. |
| **Claimed (Objective)** | An Objective a villain completed first. They keep the card and its reward, and it counts towards winning. |
| **Do it / Have it** | The two kinds of Objective: *do it* (event) is claimed the moment it happens; *have it* (state) is checked at the end of each End Phase, with turn order breaking ties. |
| **Dungeon** | A player's row of built Rooms between the Overworld and the Villain. |
| **Room** | A Dungeon card. It makes up your dungeon and can hold a Champion. |
| **Champion** | A hired mercenary placed in a Room. Gives bonuses and has effects based on pay. |
| **Overworld** | A player's 4×4 grid of Terrain that Heroes cross before reaching the dungeon. |
| **Wasteland** | An empty Overworld square with no Terrain. Every square starts this way. |
| **Terrain** | A card placed on an Overworld square. Always drafted with a Monster. |
| **Monster** | Guards a Terrain square. Has a preferred terrain type. Can be moved. |
| **Market** | A face-up row of cards, oldest on the left. Taken cards are replaced on the right, and the oldest is discarded each round. |
| **Treasure Market** | The market of Treasure cards, bought in the End Phase. |
| **Dungeon Market** | The market of Room cards. |
| **Terrain Market** | The market of Terrain + Monster pairs. |
| **Town** | The shared area where Heroes wait. Each Region has its own Town. |
| **Building** | One per hero class in the Town. Holds hero overflow, which causes effects. |
| **Town Phase** | The part of a round when players draft from the markets and build. |
| **Lure** | Pulling a Hero from the Town to your dungeon with treasure. |
| **Treasury** | The treasure stored in your dungeon. It sets which Heroes you can lure. |
| **Hero** | An enemy. Has a class (Warrior, Mage, Acolyte, Rogue) and a tier (Common, Paragon, Legendary). |
| **Item** | A relic from the Item deck that appears in the Town. It buffs the Hero carrying it and has a villain effect once Tainted. Each is typed Warrior, Mage, Acolyte or Rogue. |
| **Tainted** | An Item taken from a defeated Hero. A villain can sustain 2, and the rest are given away or stored as lures. |
| **Sustain** | Keep a Tainted Item active so you can use its villain effect (max 2). |
| **Tempt** | A step towards luring a Hero. It's automatic when your treasure meets their desire, and a die roll otherwise. |
| **Dice pool** | Roll d6 equal to a stat. Each 5 or 6 is a hit. |
| **Stack** | Rooms built on top of each other in one dungeon space. The top Room is active, and covered Rooms give a small bonus. |
| **Threat rank** | Monster, Champion or Villain. Compared with Hero tier to settle tied rolls. |
| **Monster (rank)** | The lowest threat rank: Overworld Monsters and Rooms with creatures in them. |
| **Minion** | A non-combatant lackey you give orders to. Minions empower Rooms, go to the Town to help lure, and carry out "Send a Minion to…" powers. Not the same as a Monster. |
| **Town Shop** | Where Items wait when no Hero is eligible for them. The first eligible Hero takes one. |
| **Overflow** | Heroes of one class beyond the 2 their Town building holds. Each one adds a scaling penalty for the villains. |
| **Status** | A timed condition on a Hero (Cursed, Slowed, Bleeding). It's cleared when they return to Town. |
| **Soul** | Harvested when a Hero dies. Spent in the End Phase through Rooms with a soul exchange. |
| **Treasure card** | A Treasure you can make once your total souls harvested reaches its printed threshold, by paying its Coin cost. |
| **Soul exchange** | A Room ability: "While this Room is in your dungeon, you can exchange X souls for Y." |
| **Trick** | An action card. Most are discarded after use. Spells are exhausted instead. |
| **Spell** | A Trick sub-type that becomes Exhausted after use and refreshes after its printed number of Upkeeps. |
| **Exhausted** | A used Spell waiting to refresh. |
| **Region** | A scenario that sets card themes, the Town and the Hero deck. |
